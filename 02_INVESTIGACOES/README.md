# 02 — Investigações

Esta pasta contém as investigações formais do projeto **O Infinito que se Experimenta**.

## Regra de rastreabilidade

Cada investigação recebe um identificador permanente:

`I### — Nome da investigação`

Exemplo:

`I001 — Presciência Divina × Livre-Arbítrio`

O ID deve ser usado em:

- Diário de Atividades;
- Questões & Perspectivas;
- documentos de evidência;
- debates entre contribuidores;
- revisões da hipótese;
- sínteses finais.

## Estrutura de uma investigação

Toda investigação deve, quando aplicável, conter:

1. pergunta central;
2. hipótese(s) testada(s);
3. origem da questão;
4. evidências favoráveis;
5. evidências contrárias;
6. modelos/explicações concorrentes;
7. distinção entre fato, interpretação, hipótese e especulação;
8. contribuições dos participantes;
9. estado atual;
10. próximas etapas;
11. documentos relacionados.

## Integridade histórica

Uma investigação concluída ou revisada não deve ser apagada para refletir uma nova conclusão.

Se uma revisão alterar substancialmente uma hipótese, deve ser criado um registro de revisão vinculado ao ID original.
